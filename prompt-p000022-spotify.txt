## PARTE A — P000022 debe imprimir cualquier snippet en head/body

Objetivo: que en P000022 se pueda pegar cualquier código de GTM, Google Analytics,
Meta Pixel o combinaciones, y que el sistema decida solo qué va al `<head>` y qué
al `<body>`. Debe aceptar: snippet completo de GTM, solo el script de GTM, solo un
ID `GTM-XXXXXXX`, GA4 (`gtag/js`), Meta Pixel, o GTM + píxel juntos. Nada debe
duplicarse ni quedar en la sección equivocada.

### A1. Crear `app/Support/PageSnippet.php`

Crea la clase EXACTAMENTE con esta lógica (cópiala tal cual; solo ajusta el
namespace del modelo si en este proyecto es distinto a `App\Models\Parameter`):

```php
<?php

namespace App\Support;

use App\Models\Parameter;

/**
 * Reparte el HTML/scripts guardados en el parametro P000022 entre el head y el
 * body de las paginas. Acepta codigo arbitrario y el snippet completo de GTM.
 *
 * Reglas:
 *  - Los marcadores <!-- HEAD --> y <!-- BODY --> separan explicitamente ambas partes.
 *  - Un snippet completo de GTM se corta en su comentario "Google Tag Manager (noscript)".
 *  - Si solo viene el script de GTM, el noscript se genera con el ID del contenedor.
 *  - Los bloques <noscript> se envian al body.
 *  - El HTML de cuerpo (div, iframe, img, etc.) se envia al body.
 *  - Scripts, estilos, metas y links se quedan en el head.
 */
class PageSnippet
{
    public const PARAMETER_CODE = 'P000022';

    private const GTM_NOSCRIPT_MARKER = '<!-- Google Tag Manager (noscript) -->';

    private const BODY_MARKER = '/<!--\s*(?:P000022:)?BODY\s*-->/i';

    private const HEAD_MARKER = '/<!--\s*(?:P000022:)?HEAD\s*-->/i';

    private const BODY_ONLY_TAGS = '/<(?:div|section|article|header|footer|main|aside|nav|p|span|a|img|picture|iframe|video|audio|canvas|svg|table|form|input|select|textarea|button|ul|ol|li|h[1-6])\b/i';

    /**
     * @return array{head: string, body: string}
     */
    public static function parts(): array
    {
        $html = self::raw();

        if ($html === '') {
            return ['head' => '', 'body' => ''];
        }

        // 1. Separacion explicita con marcadores.
        if (preg_match(self::BODY_MARKER, $html)) {
            [$head, $body] = preg_split(self::BODY_MARKER, $html, 2);
            $head = preg_replace(self::HEAD_MARKER, '', $head);

            return ['head' => trim($head), 'body' => trim($body)];
        }

        if (preg_match(self::HEAD_MARKER, $html)) {
            return [
                'head' => trim(preg_replace(self::HEAD_MARKER, '', $html)),
                'body' => '',
            ];
        }

        // 2. Snippet completo de Google Tag Manager (script + noscript).
        if (str_contains($html, self::GTM_NOSCRIPT_MARKER)) {
            [$head, $body] = explode(self::GTM_NOSCRIPT_MARKER, $html, 2);

            return [
                'head' => trim($head),
                'body' => self::GTM_NOSCRIPT_MARKER . "\n" . trim($body),
            ];
        }

        // 3. Solo el script de GTM: el noscript se genera con el ID, salvo que
        //    ya venga en el codigo. Los <noscript> que haya (p. ej. un pixel) van al body.
        if (preg_match('/GTM-[A-Z0-9]+/', $html, $matches)) {
            $containerId = $matches[0];
            $noscripts = [];

            $head = preg_replace_callback(
                '/<noscript\b[^>]*>.*?<\/noscript>/is',
                function (array $found) use (&$noscripts) {
                    $noscripts[] = $found[0];

                    return '';
                },
                $html
            );

            $body = [];

            if (! str_contains($html, 'googletagmanager.com/ns.html')) {
                $body[] = self::GTM_NOSCRIPT_MARKER . "\n"
                    . '<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=' . $containerId . '"'
                    . ' height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>' . "\n"
                    . '<!-- End Google Tag Manager (noscript) -->';
            }

            array_push($body, ...$noscripts);

            return [
                'head' => trim($head),
                'body' => trim(implode("\n", $body)),
            ];
        }

        // 4. Cualquier <noscript> pertenece al body.
        if (preg_match_all('/<noscript\b[^>]*>.*?<\/noscript>/is', $html, $matches)) {
            return [
                'head' => trim(str_replace($matches[0], '', $html)),
                'body' => trim(implode("\n", $matches[0])),
            ];
        }

        // 5. Etiquetas de contenido (widgets, imagenes, iframes...) van al body.
        if (preg_match(self::BODY_ONLY_TAGS, $html)) {
            return ['head' => '', 'body' => trim($html)];
        }

        // 6. Scripts, estilos, metas y links se quedan en el head.
        return ['head' => trim($html), 'body' => ''];
    }

    /**
     * Indica si el contenido guardado en P000022 incluye el texto dado.
     */
    public static function contains(string $needle): bool
    {
        return $needle !== '' && str_contains(self::raw(), $needle);
    }

    private static function raw(): string
    {
        $value = trim((string) Parameter::query()
            ->where('parameter_code', self::PARAMETER_CODE)
            ->value('value_default'));

        // El parametro pudo guardarse escapado una o varias veces desde el
        // formulario de parametros; se decodifica hasta obtener el HTML real.
        for ($i = 0; $i < 3; $i++) {
            $decoded = htmlspecialchars_decode($value, ENT_QUOTES);

            if ($decoded === $value) {
                break;
            }

            $value = $decoded;
        }

        return trim($value);
    }
}
```

Puntos que NO debes "mejorar" ni simplificar, porque son correcciones de errores
reales ya detectados:
- En la regla 3 el `<noscript>` debe salir del head con `preg_replace_callback` y
  viajar al body. Si el body se llenara solo con el iframe de GTM, un Meta Pixel
  pegado junto a GTM terminaría en el head y no dispararía.
- Solo genera el `<noscript>` de GTM si el código no trae ya
  `googletagmanager.com/ns.html`, para no duplicarlo.
- `raw()` decodifica entidades hasta 3 veces porque el formulario pudo guardar el
  HTML escapado.

### A2. El controlador de parámetros no debe escapar P000022

En `store()` y en `update()`, hoy los `control_type = 'tx'` pasan por
`htmlspecialchars()`. P000022 debe guardarse TAL CUAL. Deja el resto igual:

```php

// P000022 guarda el codigo de Google Tag Manager tal cual; el resto de
// textareas se sigue escapando para no inyectar HTML.

    $value_default = $request->get('value_default');

```

No cambies la validación existente. No escapes P000022 en ningún otro punto.

### A4. Migración(es) idempotentes para P000022

```php
<?php

use App\Models\Parameter;
use Illuminate\Database\Migrations\Migration;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\File;
use Illuminate\Support\Facades\Schema;

return new class extends Migration

Los bloques <noscript> y el HTML de cuerpo se envian al body automaticamente. Acepta el snippet completo de Google Tag Manager.';

    public function up(): void
    {
        if (! Schema::hasTable('parameters')) {
            return;
        }

        $this->expandTextColumns();

        $parameter = Parameter::where('parameter_code', 'P000022')->first();

        if (! $parameter) {
            Parameter::create([
                'parameter_code'  => 'P000022',
                'description'     => self::DESCRIPTION,
                'control_type'    => 'tx',
                'json_query_data' => null,
                'value_default'   => null,
            ]);

            return;
        }

        $value = (string) $parameter->value_default;

        // Si el valor solo repite un GA4 que ya esta fijo en el layout, se
        // respalda y se limpia para no duplicar metricas al imprimirlo.

            $backup = storage_path('app/p000022-legacy.html');

            if (! File::exists($backup)) {
                File::put($backup, $value);
            }

            $parameter->value_default = null;
        }

        $parameter->description = self::DESCRIPTION;
        $parameter->save();
    }

    /**
     * Amplia las columnas para que acepten HTML/scripts largos. Es idempotente:
     * volver a aplicar el mismo tipo no cambia nada. En sqlite TEXT ya no tiene
     * el limite practico de varchar(255), por eso solo se altera MySQL.
     */
    private function expandTextColumns(): void
    {
        if (! Schema::hasColumn('parameters', 'description')
            || ! Schema::hasColumn('parameters', 'value_default')
            || DB::getDriverName() !== 'mysql') {
            return;
        }

        DB::statement('ALTER TABLE `parameters` MODIFY `description` TEXT NOT NULL');
        DB::statement('ALTER TABLE `parameters` MODIFY `value_default` LONGTEXT NULL');
    }

    public function down(): void
    {
        // No se revierten los tipos para no truncar el contenido guardado, ni se
        // restaura el valor anterior para no reactivar etiquetas duplicadas.
    }
```

- `down()` vacío a propósito, con el comentario incluido.

## PARTE B — Canales UTM de Spotify en las landings de cursos

Objetivo: que el generador de enlaces UTM de cada landing de curso incluya Spotify,
y que el dashboard de atribución lo muestre correctamente. NO se necesita migración:
la configuración se guarda en el JSON `utm_config` de la landing.

### B1. Agregar tres canales en el arreglo `baseChannels`

En el componente que genera los UTM de las landings de cursos
(`LandingUtmLinks.vue` o su equivalente), dentro de `baseChannels`, añade estas
entradas antes del bloque de Email:

```js
// Spotify
{ id: 'spotify_bio', label: 'Spotify Bio', icon: 'fa-brands fa-spotify', color: '#1DB954', utm_source: 'spotify', utm_medium: 'social', origen: 'Social' },
{ id: 'spotify_playlist', label: 'Spotify Playlist', icon: 'fa-brands fa-spotify', color: '#1DB954', utm_source: 'spotify', utm_medium: 'referral', origen: 'Social' },
{ id: 'spotify_ads', label: 'Spotify Ads', icon: 'fa-brands fa-spotify', color: '#1DB954', utm_source: 'spotify', utm_medium: 'cpc', origen: 'Spotify' },
```

Detalles que importan:
- El desglose "Social" del dashboard se arma con `channelByKey`, que se deriva de
  `baseChannels` (clave `${utm_source}_${utm_medium}`). Al añadir los canales aquí,
  sus nombres e íconos aparecen solos en el reporte; no hay que tocar el
  controlador ni el arreglo `originRows`.
- `spotify_bio` usa `utm_medium=social` y `spotify_playlist` usa `referral` para
  que el clasificador los cuente como Social. `spotify_ads` usa `cpc` porque es
  publicidad pagada y debe contarse como CPC, con origen "Spotify".
- No agregues una fila nueva a `originRows`: agruparía mal los datos.
- Los enlaces se generan con el formato existente:
  `<base>/curso/{slug}?utm_source=spotify&utm_medium=...&utm_campaign=curso_<slug>`
  y, si el usuario llena `utm_term`/`utm_content`, se añaden. La campaña por
  defecto es `curso_` + el slug con guiones cambiados por guiones bajos. No cambies
  esa lógica, solo se alimenta de los canales nuevos.
- No toques el resolver de fuentes del CRM (`TrafficSourceResolver`) para esto: no
  participa en el reporte de la landing.

### B2. Clasificar Spotify como Social en `public/js/traffic-tracking.js`

El script de atribución clasifica el tráfico y guarda `traffic_source` en
`localStorage` (clave `traffic_tracking`, TTL 24h, first-touch). Añade Spotify a la
rama de redes sociales, DESPUÉS de las ramas de pago:

```js
if (fbclid || (isFacebook && isPaidMedium)) {
    trafficSource = 'facebook_ads';
} else if (gclid || (isGoogle && isPaidMedium)) {
    trafficSource = 'google_ads';
} else if (isFacebook || /(instagram|tiktok|youtube|linkedin|twitter|threads|whatsapp|^x$)/.test(src) || (src === 'spotify' && !isPaidMedium)) {
    trafficSource = 'social';
} else if (isGoogle) {
    trafficSource = 'organic';
} else if (isPaidMedium) {
    trafficSource = 'cpc';
} else if (/social/.test(med)) {
    trafficSource = 'social';
}
// ... resto igual
```

La condición `(src === 'spotify' && !isPaidMedium)` es la clave: sin ella, Spotify
caería en `referrer` (por el referrer) o en `cpc`, y el desglose Social quedaría
vacío. `isPaidMedium` ya existe en el archivo (`/(paid|cpc|ppc|ads)/`) y debe seguir
evaluándose antes, para que `spotify_ads` cuente como CPC.

Comprueba además que el script esté cargado en el layout de la landing pública
(`<script src="{{ asset('js/traffic-tracking.js') }}"></script>`). Si solo está en
un layout y las landings usan otro, agrégalo en el que corresponda. No dupliques la
etiqueta si ya está incluida.
